# Fake News Detection System

This project focuses on detecting fake and real news articles using machine learning techniques.

## Overview
The system analyzes news content and predicts whether the article is fake or genuine.

## Project Structure
- `main.ipynb` — Main notebook containing model training and prediction workflow
- `README.md` — Project documentation

## Features
- News classification
- Data preprocessing
- Machine learning workflow
- Prediction system
